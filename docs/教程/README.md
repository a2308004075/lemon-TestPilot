# TestPilot 从0开发 · 详细分册版

> **把一个「个人测试智能工作台」从空文件夹搭到能上线：完整代码 · 手把手步骤 · 原理与取舍**
>
> - 读者定位：有编程基础、想通过一个完整真实项目提升全栈能力的开发者
> - 学习方式：跟着分册从零重建项目，每章对照真实源码与界面截图
> - 配套材料：[用户操作手册](../用户操作手册.md)（成品功能说明）· 项目源码本身

## 一、与速览版的关系

本教程由单文件速览版《[从0开发教学](../从0开发教学.md)》（约 1700 行）拆分、扩写而来。旧文件保留为入口指引，内容以本目录为准：

| | 速览版 | 详细分册版（本目录） |
| --- | --- | --- |
| 组织形式 | 单文件 12 章 | 每章一个文件 + 本总目录导航 |
| 代码 | 节选「教学版片段」 | **完整可运行代码全量展开**（附录 C 附全量装配参考） |
| 步骤 | 要点式罗列 | **手把手**：每步做什么 → 跑什么命令 → 看到什么 → 如何验证 |
| 原理 | 一两句带过 | **深挖**：背景、备选方案对比、真实坑的来龙去脉 |

## 二、详细版加强了什么

1. **完整代码全量展开**：每章给出可直接复制运行的完整代码（含真实源码中被省略、压缩的部分），逐段讲解「这段在干什么、为什么这样写」。全书代码在附录 C 可一次性拿到装配后的完整形态；
2. **手把手操作步骤**：步骤拆到「打开哪个文件、写什么、敲什么命令、终端输出应该是什么、浏览器/接口应该看到什么」，每章结尾都有一份验证清单；
3. **原理与取舍深挖**：每个设计决定补充背景与原理（如 WAL 是什么、DPAPI 怎么工作、幂等为何重要）、备选方案对比（表格化）、真实坑的复现与排查方法。

> 说明：整体章节骨架（第 0–12 章）与速览版保持一致，便于两版对照阅读。

## 四、每章的阅读结构

每章统一六个小节，可以先看 🔍 定位，再回看 🛠 的完整代码：

| 小节 | 回答的问题 |
| --- | --- |
| 🎯 本章目标 | 这一步要做出什么、做完你能验证什么 |
| 🚧 前置条件 | 开始本章前，你的项目应该处于什么状态 |
| 🧠 设计思路与原理 | 为什么这样做、有哪些替代方案、背后是什么原理 |
| 🛠 动手步骤 | 手把手：完整代码 + 命令 + 预期结果，步步可验证 |
| 🔍 对照真实项目 | 本章内容对应哪个文件的哪几行（精确到函数） |
| ⚠️ 要点与坑 | 真实踩过的坑、边界条件、排查方法 |
| ✍️ 练习 | 巩固理解的小任务（做完对答案见第 12 章里程碑） |

## 五、学习路线

- 第 1 周 · 后端打底：第 2–5 章（环境 → HTTP 服务器 → 数据层 → 通用 API）
- 第 2 周 · 前端与引擎：第 6–8 章（前端骨架 → 页面模式 → 工作流引擎，本周核心）
- 第 3 周 · 进阶能力：第 9–11 章（模型接入 → 工程化部署 → 数据迁移）
- 贯穿全程：每章结尾练习；第 12 章有 M1–M5 里程碑的完整验收标准

## 六、阅读建议

1. **先跑通，再深究**：第 2–3 章先把项目跑起来，后面每章都能在浏览器里看到成果，学习动力完全不同；
2. **对照源码读**：每章 🔍 小节给了精确行号，读完教学版代码就翻到真实文件里看压缩版原文——先看懂，再适应真实风格；
3. **代码不要「读」，要「敲」**：至少把第 3–5 章的代码亲手敲一遍，跑起来验证，练习别跳过；
4. **行号会漂移**：源码更新后行号可能变化，请以函数/组件名定位（附录 A 有完整索引）；
5. **遇到报错先查附录 B**：命令速查里有一张「常见错误 → 处理」对照表。

## 七、环境要求

- **Node.js 24 LTS 或更高**（项目依赖 `node:sqlite`，低版本无法运行）；
- 任意编辑器（VS Code / WebStorm / PyCharm 均可），推荐装上 React 与 TypeScript 插件；
- 终端：Windows 用 PowerShell（本文命令均已适配），macOS 用默认 zsh 即可；
- 浏览器：Chrome / Edge / Safari 任意现代浏览器。
